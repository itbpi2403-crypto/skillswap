# SkillSwap - Детальное резюме проекта

## 🎯 Обзор проекта

**SkillSwap** - это инновационная веб-платформа для взаимного обучения внутри университетского сообщества. Проект позволяет студентам обмениваться знаниями и навыками без денежных расчетов, используя внутреннюю систему баллов.

### 📊 Основные метрики
- **Тип:** Веб-платформа (Full-Stack приложение)
- **Статус:** MVP (Минимальная жизнеспособная версия)
- **Команда:** 7 человек
- **Технологии:** Modern JavaScript Stack
- **Архитектура:** Микросервисная (Backend + Frontend)

## 🚀 Ключевые возможности

### Реализовано в MVP
- ✅ Регистрация и аутентификация пользователей
- ✅ Создание и редактирование профиля с навыками
- ✅ Система поиска пользователей по навыкам
- ✅ Внутренняя валюта ("кредиты")
- ✅ Система запросов на обучение

### Планируется в ближайших релизах
- 🔄 Система чата в реальном времени
- 🔄 Календарь для планирования сессий
- 🔄 Рейтинги и отзывы
- 🔄 Уведомления по email и в приложении
- 🔄 Мобильное приложение

## 🗄️ Модель данных

### Основные сущности

#### User (Пользователь)
```typescript
{
  id: number;           // Уникальный идентификатор
  email: string;        // Email (уникальный)
  password: string;     // Хешированный пароль
  name: string;         // Имя пользователя
  bio?: string;         // Биография
  credits: number;      // Баланс кредитов
  skills: Skill[];      // Навыки для преподавания
  learn: Skill[];       // Навыки для изучения
  createdAt: DateTime;
  updatedAt: DateTime;
}
```

#### Skill (Навык)
```typescript
{
  id: number;           // Уникальный идентификатор
  name: string;         // Название навыка (уникальное)
  users: User[];        // Кто преподает этот навык
  learn: User[];        // Кто изучает этот навык
}
```

#### Request (Запрос на обучение)
```typescript
{
  id: number;           // Уникальный идентификатор
  fromUserId: number;   // ID отправителя
  toUserId: number;     // ID получателя
  skillId: number;      // ID навыка
  status: RequestStatus;// Статус: PENDING/ACCEPTED/REJECTED
  createdAt: DateTime;
  updatedAt: DateTime;
}
```

## 🚀 Быстрый старт для разработчиков

### Предварительные требования
- Docker & Docker Compose
- Git
- Node.js 18+ (опционально, для локальной разработки)

### Запуск за 3 шага
```bash
# 1. Клонирование репозитория
git clone https://github.com/itbpi2403-crypto/skillswap.git
cd skillswap

# 2. Настройка окружения
cp backend/.env.example backend/.env
cp frontend/.env.example frontend/.env

# 3. Запуск всех сервисов
docker-compose up
```

### Доступ к сервисам
- **Frontend:** http://localhost:3000
- **Backend API:** http://localhost:3001
- **API Documentation:** http://localhost:3001/api
- **Database:** PostgreSQL на localhost:5432
